# 998webdesigns-templates — Project Handoff

Sibling to `998webdesigns-com-app`. This is the **template gallery** — a filterable grid of 57 industry-specific website starting points that prospects can browse before they sign up.

## Status (v0.1, 2026-05-21)

Local-only until first push. Stack: Next.js 16 + Tailwind v4 + 57 Crafto industry homepages served as static assets from `/public/t/`. Auto-screenshots generated by `scripts/screenshot-templates.mjs`. Deploys to Vercel.

## How to add a new template

1. Drop the template's homepage HTML at `public/t/demo-<slug>.html` and any new assets it needs.
2. Add an entry to `templates` in `src/data/templates.ts`:
   ```ts
   { slug: "your-slug", name: "Your Display Name", category: "Trades & local services" }
   ```
3. Re-screenshot: `npm run dev -- -p 3001` in one terminal, `node scripts/screenshot-templates.mjs` in another (after adding the new slug to the `SLUGS` array in that script).
4. Commit + push. Vercel auto-deploys.

## How to ship a change

```
git checkout -b feat/<name>
# edit
npm run dev                      # local on :3000
npm run build                    # confirm prod build passes
git add . && git commit -m "<ascii-only msg>"
git push -u origin feat/<name>
# review the Vercel preview URL, then merge
```

Rules:
- Never push directly to `main`; branch first.
- ASCII-only commit messages.
- Bump `SITE_VERSION` in `src/lib/version.ts` by one each commit.
